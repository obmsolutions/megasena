OBM MEGA ANALYTICS v2.0
=======================

COMO EXECUTAR
Opção recomendada:
1. Instale o Node.js 18 ou superior.
2. Abra o terminal dentro desta pasta.
3. No Windows, dê dois cliques em INICIAR.bat. Alternativamente execute: npm run serve
4. Abra no navegador: http://localhost:8080

Também é possível abrir index.html diretamente. A base histórica e as bibliotecas essenciais estão incluídas no pacote. Alguns navegadores podem restringir Workers quando páginas são abertas por file://; nesse caso use o servidor local acima.

TESTES AUTOMATIZADOS
Execute: npm test

NOVIDADES DA FASE 2
- HTML, CSS e JavaScript separados.
- Motor central compartilhado de filtros e importação.
- Base local com 3.038 concursos em JSON e JavaScript offline.
- Cache local e sincronização incremental com a API da Caixa.
- Geração de jogos em Web Worker.
- Retroteste em Web Worker.
- Bibliotecas de gráficos, planilhas e PDF incluídas localmente.
- Testes automatizados de filtros, importação e integridade da base.
- Estrutura pronta para evolução e backend futuro.

AJUSTE CONTROLADO DOS FILTROS
- Filtro 2: uma única faixa de soma entre 120 e 240.
- Filtro 11: opções de uma ou duas linhas vazias.
- Filtro 13: opções de quatro, cinco ou seis colunas vazias; cinco fica pré-selecionada.

AVISO
A análise estatística organiza escolhas e carteiras, mas não garante premiação. A Mega-Sena continua sendo um jogo de azar.
